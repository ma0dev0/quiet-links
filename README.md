# Quiet Links

Quiet Links は、ダークモード固定のミニマルなリンクダッシュボードです。
よく使うサイトを 1 画面に集めて、検索・お気に入り・カテゴリ切り替えで素早く開けます。

## できること

- `index.html` だけで動く静的アプリ
- 名前、説明、カテゴリ、タグでリンクを検索
- 一致した検索語をカード内でハイライト
- キーボードから検索欄へすぐ移動
- カテゴリごとに整理して一覧表示
- カテゴリ名の変更とカテゴリ順の並び替え
- よく使うリンクを上部に固定表示
- リンクの追加・編集、お気に入り切り替え、追加したリンクの削除
- 削除直後の取り消し
- カテゴリ内でのリンクの並び替え
- 任意のカテゴリを入力してリンクを整理
- ブラウザの `localStorage` に保存して次回もそのまま使える
- JSONでリンク一覧をエクスポート、インポート

## 使い方

### ローカルで開く

1. このリポジトリを取得する
2. `index.html` をブラウザで開く
3. 右上の `追加` からリンクを増やす
4. 検索欄とカテゴリタブで絞り込む
5. カードの編集ボタンから保存済みリンクを見直す
6. 必要に応じてインポート、エクスポートでリンク一覧をバックアップする

### GitHub Pages に公開する

1. `main` ブランチに push する
2. GitHub Pages の公開元をリポジトリのルートに設定する
3. 公開 URL を開く

## データの保存

- 初回起動時は、あらかじめ入っているデフォルトリンクが表示されます
- 追加したリンクやお気に入りは、このブラウザの `localStorage` に保存されます
- 保存キーは `quiet-links-services-v1` です
- ブラウザのサイトデータを消すと、保存した内容もリセットされます
- 大事なリンクを入れた後は、JSONでエクスポートしておくと復元できます

## カスタマイズ

デフォルトのリンク一覧は `index.html` の `defaultServices` を編集すると変更できます。
このプロジェクトは 1 ファイル構成なので、ビルド作業は不要です。

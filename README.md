# Quiet Links

Quiet Links は、毎日使うサイトへ迷わず移動するためのパーソナルリンクダッシュボードです。
最初に「いつものリンク」だけを見せ、使うほど「最近使った」が育つため、管理画面を探し回らず目的地を開けます。

## できること

- `index.html` だけで動く静的アプリ
- 名前、説明、カテゴリ、タグでリンクを検索
- 検索結果の先頭を `Enter` で開く
- 一致した検索語をカード内でハイライト
- キーボードから検索欄へすぐ移動
- お気に入りだけを集めた「ホーム」
- 開いた回数と最終利用日時にもとづく、よく使う順・最近使った順の自動整理
- カテゴリごとに整理して一覧表示
- 日常の閲覧画面と、星付け・編集・並べ替えを行う「整理モード」の分離
- カテゴリ名の変更とカテゴリ順の並び替え
- よく使うリンクを上部に固定表示
- リンクの追加・編集、お気に入り切り替え、追加したリンクの削除
- 削除直後の取り消し
- カテゴリ内でのリンクの並び替え
- 任意のカテゴリを入力してリンクを整理
- ブラウザの `localStorage` に保存して次回もそのまま使える
- JSONでリンク一覧をエクスポート、インポート

## 使い方

### ローカルで開く

1. このリポジトリを取得する
2. `index.html` をブラウザで開く
3. 右上の `整理` を押し、よく使うリンクへ星を付ける
4. 必要なら整理モード内の `追加` からリンクを増やす
5. 普段は `ホーム`、検索欄、カテゴリタブからリンクを開く
6. 検索中は `Enter` で先頭の結果を開く（`/` で検索欄へ移動）
7. 必要に応じて整理モード内のインポート、エクスポートでリンク一覧をバックアップする

### GitHub Pages に公開する

1. `main` ブランチに push する
2. GitHub Pages の公開元をリポジトリのルートに設定する
3. 公開 URL を開く

## データの保存

- 初回起動時は、あらかじめ入っているデフォルトリンクが表示されます
- 追加したリンクやお気に入りは、このブラウザの `localStorage` に保存されます
- リンクを開いた回数と最終利用日時も同じ場所へ保存され、「いつものリンク」と「最近使った」の並び順に使われます
- 利用履歴は外部へ送信されません
- 保存キーは `quiet-links-services-v1` です
- ブラウザのサイトデータを消すと、保存した内容もリセットされます
- 大事なリンクを入れた後は、JSONでエクスポートしておくと復元できます

## カスタマイズ

デフォルトのリンク一覧は `index.html` の `defaultServices` を編集すると変更できます。
このプロジェクトは 1 ファイル構成なので、ビルド作業は不要です。
